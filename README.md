# AI Motivational Quote Generator

## Project Description
This is a simple AI-based motivational quote generator built using Python. The user enters a mood, and the program displays a motivational quote based on the input.

## Features
- Accepts user mood as input
- Displays motivational quotes
- Easy to use
- Beginner-friendly Python project

## Technologies Used
- Python
- Google Colab

## How to Run
1. Open the notebook in Google Colab.
2. Run the code.
3. Enter a mood (e.g., happy, sad, tired, success).
4. Get a motivational quote.
